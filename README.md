# AstraHealth

This repository contains two separate healthcare software prototypes:

- [LoopGuard](loopguard/): radiology follow-up tracking, with a Python/FastAPI
  backend and React/TypeScript frontend. Its README explains the workflow,
  development setup, and implementation limits.
- [Myndra](Myndra/): a separate project directory with its own implementation.

For the LoopGuard Software Engineering course project, begin in `loopguard/`.
The two directories should not be treated as one completed application.
